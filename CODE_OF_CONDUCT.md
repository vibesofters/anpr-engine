# Code of Conduct

ANPR Engine adopts [Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) for project spaces and interactions. The linked text is the governing standard; this project does not modify its behavioral rules.

Report conduct concerns privately to [erncnkr@gmail.com](mailto:erncnkr@gmail.com). The maintainer will review reports confidentially where practical and may moderate participation to protect the community. Do not include real plate images, plate text, or other sensitive personal data in a public issue.

This adoption and version attribution are separate from the software license.
