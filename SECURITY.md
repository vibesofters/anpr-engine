# Security policy

Please do **not** disclose a suspected vulnerability in a public issue, discussion, or pull request. Email [erncnkr@gmail.com](mailto:erncnkr@gmail.com) with a concise description, affected version or commit, reproduction steps using synthetic data, and expected impact. Do not send real plate images, credentials, or personal information unless a safe exchange has been agreed first.

The maintainer will acknowledge and investigate reports on a best-effort basis. This project does not promise a fixed response time or security-support period. Coordinated disclosure should wait until the issue has been assessed and a reasonable remediation plan is agreed.

Never use the public demonstration to test third-party systems, bypass usage limits, or submit images without authorization.
