# Recognizer registry boundary

The curated public record for the selected project Recognition model is
`../public/recognition-cnn-transformer-dual-slot-tr-v1.json`.

The model weights and record-level training or evaluation evidence remain
private and are not distributed. The public record contains only the approved
immutable identity, percentage-only development-validation metrics,
architecture summary, limitations, provenance, and citations. It is not a
public model-weight release or a production-readiness claim.
